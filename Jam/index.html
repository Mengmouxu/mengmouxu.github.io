Abstract

World action models (WAMs) provide temporal supervision for robot control by predicting how observations evolve in demonstrations. Existing approaches, however, commonly predict targets in a fixed visual representation space, or rely on costly sampling-based planning over visual goals rather than direct language-guided control. We introduce JAM, a Joint-Embedding Predictive Action Model for multi-view, language-guided robot control that encodes each observation into a single state token for causal modeling over the observation history. Trained end-to-end with transition and action losses, JAM learns a single representation for both dynamics and control. Within this embedding space, the shared causal predictor serves as both a world model and a control policy. Given an action segment, it forecasts the next state transition; given a language instruction, it jointly generates an action chunk and predicts the resulting state change. At deployment, our 0.09B policy generates action chunks in closed loop from RGB observations and language instructions, without proprioceptive input. With a single forward pass per chunk, it runs 10.1× and 20.1× faster than π0.5 and Fast-WAM, respectively, while achieving 98.4% average success on LIBERO. On RoboTwin 2.0, a 0.37B variant reaches 82.54% average success.

Benchmark results

On LIBERO, JAM matches the success of several larger policies with lower query latency. On RoboTwin 2.0, Base improves over Small in both settings. The strongest baselines retain an advantage, particularly on Random.

With BF16 on 80 GB A100 GPUs, training on LIBERO takes about 2 hours for 16,000 updates on four GPUs, with a sampled peak of 31.5 GiB per GPU. RoboTwin 2.0 Base is projected to take about 47 hours for 200,000 updates on eight GPUs, with 55.5 GiB per GPU observed at peak in a training profile.

Representation analysis

JAM compresses the RGB views at each time step into one scene token. We test what this token retains about the robot's state and motion, then visualize how the representation evolves during manipulation.

Frozen-feature probes on LIBERO

We fit affine and MLP readouts to frozen features at their original dimensions. The position readout estimates the current end-effector location. The motion readout also receives the recorded actions and estimates the resulting displacement.
